# 功能清单与实现位置

按模块列出已实现的功能及对应代码位置，便于阅读与二次开发。

## GPT-SoVITS 文字配音

- 权重切换：`/set_gpt_weights`（GPT `.ckpt`）、`/set_sovits_weights`（SoVITS `.pth`），合成走 `/tts`
- 请求参数：参考音频、参考文本与语言、合成语言、语速、采样步数、切分方法、片段间隔
- 切分方法按真实语义映射：`cut0` 不切、`cut1` 四句、`cut2` 约 50 字、`cut3` 中文句号、`cut4` 英文句号、`cut5` 标点
- 角色档案可增删改，支持搜索与分组；生成结果落盘、记录、自动试听与导出
- 输出文件名消毒，同名不覆盖

## RVC / UVR / FFmpeg 翻唱工作台

- 模型扫描：`.pth`、`.index` 与 UVR 模型，支持附加模型目录
- 五种动作：一键翻唱混音、单独分离人声、单独分离伴奏、独立换声、独立混音
- 参数：说话人 ID、变调、F0 算法、索引比例、滤波半径、重采样率、音量包络、无声保护、UVR 聚合度、输出格式、伴奏与人声音量
- WAV / FLAC / MP3 导出；人声、伴奏、换声结果与混音成品都可继续作为下一步输入
- 阶段进度、日志、队列、取消与错误重试

## 实时变声

- 设备枚举与选择（WASAPI / DirectSound / MME / WDM-KS）
- 模型推理，输出到耳机或虚拟音频端点
- 显式启停、遥测、可选录制、设备失败恢复

## 音频工具

- 扫描目录、选择单个或批量 NCM 文件，逐个解密转换并汇报成功与失败
- 转换产物可以直接送去翻唱，作为后续处理的输入

## 任务与存储

- 配音、翻唱与 NCM 转换统一排队，GPU 任务串行调度
- 持久化任务记录与作品库；清除记录不会删除音频文件
- 偏好、声音档案与任务历史保存在 `%APPDATA%\smartchat\mutsumi-audio-studio\studio-state-v3.json`；首次运行会从 2.x 的数据迁移，旧文件不改动
- 开发测试可用环境变量 `MUTSUMI_USER_DATA` 指定独立数据目录

## 界面与主题

- 七个页面：文字配音、翻唱换声、实时变声、音频工具、声音库、任务与作品、设置
- 两套主题（浅色 / 深色），各自使用独立素材
